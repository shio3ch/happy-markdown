# 開発・検証・配布

## 開発環境

Node.js 22以上、npm、VS Code 1.100.0以上を使用します。拡張の対応バージョンと実行可能なスクリプトは `package.json` を確認してください。

```sh
npm ci
npm run build
npm test
```

`npm ci` は初回セットアップや依存変更時に実行します。ビルドはesbuild、自動テストはNode.js標準のテストランナーを使用します。現在、lint・型チェックのnpmスクリプトはありません。

## 自動検証

JavaScriptや依存関係を変更したらビルドとテストを実行します。対象を絞る場合は次のように指定できます。

```sh
node --test test/session.test.js
```

不具合修正では可能なら回帰テストを追加し、期待する挙動を確認します。文書のみの変更は、記載内容・パス・リンク・コマンドの整合性を確認します。

## VS Code上の確認

F5で拡張開発ホストを起動します。起動前のタスクでビルドが実行されます。`examples/preview.md` を確認用文書として使います。ソース変更後は再ビルドし、開発ホストを再読み込みしてください。

- 表示変更: ライト・ダークテーマ、キーボード操作、フォーカス表示。
- 編集・同期変更: 連続入力、外部編集との競合、保存・自動保存、Undo / Redo、編集とプレビューの切り替え、LF / CRLF。
- 描画変更: 専用画面と標準Markdownプレビューの影響範囲。

自動テストと実際のVS Code上の確認は区別して記録します。画面確認ができなかった場合は未確認と明記します。

## 配布物の作成

```sh
npm run package
```

VSIX作成時は `vscode:prepublish` によってビルドが実行されます。出力名は `package.json` の名前とバージョンに従います。現在の運用ではMarketplaceへの公開は行いません。

`dist/` は直接編集せず生成します。Webviewバンドルと第三者ライセンスが配布物に含まれることを確認してください。開発資料の `wiki/` と `AGENTS.md` は `.vscodeignore` で除外します。
