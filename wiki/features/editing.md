# 編集機能

- CodeMirrorによるMarkdownライブ編集、コードの色分け、インデント、選択範囲の操作、検索。
- 見出し、太字、斜体、下線、取り消し線、インラインコード、リスト、引用、水平線、リンク、画像、表、コードブロックの挿入。
- ツールバーは中央揃えのSVGアイコンを使用。各操作名はツールチップと読み上げ用ラベルで確認でき、見出しアイコンからレベルを選択できる。
- 見出しはレベル1〜7に対応。レベル7の `####### 見出し` は専用画面の拡張記法で、他のビューアとの互換性に注意が必要。下線はHTMLの `<u>…</u>` を使用。
- リスト・引用はカーソル行または選択した複数行が対象。番号付きリストは1から連番。水平線は選択内容を保持して挿入。
- 画像はファイル選択またはURLで追加。文書のフォルダー内の画像は相対パスで参照し、外部の画像は文書横の `assets` にコピー。元画像は変更しない。コピーした画像の削除はUndo対象外。

## ライブ編集

初めて開く専用画面はプレビューで起動します。「編集する」でライブ編集に切り替えられます。以前の画面状態がある場合は、編集・プレビューの選択を復元します。

Markdownの構文木に基づいて、入力と同時に見出しの大きさ、太字、斜体、取り消し線、インラインコード、下線（属性のない `<u>…</u>`）、リンクのラベル、箇条書き、引用、コードブロック、水平線の見た目を反映します。行番号を外し、本文用のフォントと幅で表示します。コード内のMarkdown記法は装飾しません。

- カーソルや選択範囲のある行では記法を表示します。装飾の見た目を保ったまま、`#` や `**`、リンク先などを直接編集できます。複数行にまたがる文字装飾は、その範囲を編集中なら記法を表示します。
- それ以外の行では対応する記法を隠し、読みやすく表示します。コードブロックでは、ブロック外を編集中ならフェンスを隠し、言語名とコードを表示します。
- タスク行の外にカーソルがある場合、チェックボックスをクリック、またはTabでフォーカスしてSpaceで切り替えられます。対象の `[ ]` / `[x]` の1文字だけを変更し、通常の編集と同じ文書同期・保存・Undo / Redo経路を使います。タスク行を編集中は記法を直接修正します。
- Enterでリストや引用の記法を継続できます。検索、書式挿入、モード切り替え時のカーソルと未保存入力の保持は引き続き利用できます。
- 日本語IMEの変換中は表示の装飾を組み直さず、確定後に更新します。
- トップレベルの閉じた `mermaid` フェンスは、ブロック外を編集中なら図として表示します。「記法を編集」ボタン（TabでフォーカスしてEnter／Spaceでも操作可能）やカーソル移動でブロックへ入ると元の記法に戻り、ブロック外へ出ると再描画します。本文・カーソル・Undo履歴を表示のために書き換えません。構文エラー時も「記法を編集」から修正できます。引用・リスト内、未閉鎖のフェンスはコードを表示します。

装飾は表示上の処理で、Markdown本文をHTMLへ変換して保存しません。リンクのラベルは装飾しますが、編集画面でのリンク先への移動は未対応です。画像・任意HTMLの描画は専用プレビューで確認します。完全なWYSIWYGや、プレビューとすべて同じ表示ではありません。

見出し・文字装飾・リンク・引用・コード・表・チェックボックス・水平線の基本書式は、プレビューと同じ `styles/preview.css` で定義します。本文の幅と外側の余白も専用画面の両モードで共通です。見出し下の装飾線は付けず、水平線はMarkdownに明示されたものを表示します。編集時に見せる記法、元文書の空行、画像など未対応の描画による違いは残ります。

この実装は[CodeMirror公式の装飾機構](https://codemirror.net/examples/decoration/)を使用し、`src/webview/live-preview.ts` に分離しています。

## テーブル

- テーブルは編集時も表のまま表示し、セルをクリックして直接入力します。Markdownのパイプや区切り行は表示しません。見出し行、列の左・中央・右寄せ、空セル、セル内の太字・斜体・取り消し線・下線・インラインコード・リンクのラベルに対応し、プレビューと同じCSSを使用します。
- Tab／Shift+Tabで前後のセルへ、Enterで同じ列の次の行へ移動します。末尾からのTab／Enterは行を追加します。Tabでは新しい行の先頭へ、Enterでは同じ列へ移動します。Shift+Enterはセル内の改行（Markdownでは `<br>`）、Escapeは表の外へ移動します。表が文書末尾にある場合は、続けて文章を書くための空行を追加します。
- 行にホバーすると左側に、見出しセルにホバーするとその列の上に、その対象だけのハンドルを表示します。ハンドルをクリックすると行・列の操作メニューを開き、前後への移動、前後への追加、対象の削除を選べます。開いたメニューはカーソルが外れても保持し、外側のクリック・フォーカス移動やEscapeで閉じます。
- ハンドルをドラッグして境界にドロップすると並べ替え、移動中のハンドルと移動先の線を表示します。セル内のAlt＋F10で行のハンドルへ移動でき、Tab／Shift+Tabで他の操作を選べます。キーボードでフォーカスしたハンドルも表示し、Alt＋上下キーで行を、Alt＋左右キーで列を移動できます。Enter／Spaceでメニューを開き、上下キー・Home・Endで項目を選べます。Escapeはメニューからハンドル、ハンドルからセルへ戻ります。ドラッグの中断や表の内容更新では移動を取り消します。
- 表の右上の「…」から、末尾への行・列の追加と「テーブルを削除」を選べます。オプションを開くだけでは文書を変更しません。見出し行を移動・削除した場合は先頭行を見出しとして扱い、最後の行・列を削除すると表全体を削除します。既存のセル内容・列配置・引用やリストの接頭辞・表の前後の文章を保持し、操作はVS CodeのUndo / Redoで戻せます。IME変換中は構造の変更を無効にします。
- ホバー中・入力中のセルは、セル全体の境界に線を重ねて強調します。行全体の背景色を塗り替えず、セル内容や列幅・高さを変えません。この操作時の表示は専用エディターだけに適用します。
- セルの変更は入力ごとに対象セルのMarkdownへ反映し、既存の文書同期・保存・Undo / Redoを使います。反映待ちの追加入力や競合したドラフトも保持します。通常の入力ではセルDOMを維持し、IME変換中は行・列の追加を無効にします。
- セル内で太字・斜体・下線・取り消し線・インラインコードのツールバー操作を使えます。Ctrl / Cmd+B・Iも対応します。編集したセルの装飾記法は正規化される場合がありますが、触れていないセルの記法は保持します。
- 入力した `|` や `*` はセル内の文字として保存します。貼り付け・ドロップではプレーンテキストを受け取り、HTMLを実行しません。改行はセル内の改行として保持します。
- コードブロック内の表記法は表として表示しません。引用・リスト内の表にも対応します。ヘッダーより短い行は空セルを補って表示し、そのセルの編集時に必要な列を補います。余分なセルはプレビューと同様に表示対象から外しますが、文書内の値は保持します。
- セル内の画像は説明文、任意HTMLは文字として扱います。リンクのラベルから外部URLへの移動は行いません。列配置の変更用の専用UIは未対応です。

表のブロック装飾は `src/webview/table-preview.ts`、入力とフォーカスは `table-view.ts`、セルの描画・Markdown変換は `table-cell.ts`、文書差分は `table-model.ts` に分離しています。
