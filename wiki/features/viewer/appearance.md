# 外観とテーマ

専用画面のツールバーにあるスライダー形の「外観をカスタマイズ」から開きます。ライブ編集とプレビューの両方に対応します。

設定中はサンプルと背後の文書へ反映し、「適用」で保存します。「キャンセル」・右上の閉じる・Escapeは保存済みの外観へ戻します。ファイル操作の処理中は完了まで待ちます。Markdown本文、文書の保存状態やUndo履歴は変更しません。

## 調整できる項目

| 項目 | 範囲・初期値 |
| --- | --- |
| 本文サイズ | 12〜32px、初期15px |
| 行間 | 1.3〜2.4、初期1.75 |
| 本文の最大幅 | 560〜1600px、初期960px。狭い画面では画面幅に収める |
| 段落の余白 | 0.5〜2.5em、初期1.25em |
| リストの字下げ | 1.5〜3.5em、初期2.2em |
| 項目の間隔 | 0〜1em、初期0.3em |
| マーカーの大きさ | 1〜1.6倍、初期1.15倍 |
| 階層ガイド | 表示・非表示、初期は表示 |
| フォント | ゴシック・明朝・VS Code設定の等幅 |
| 明るさ | VS Codeに追従・ライト・ダーク |
| 配色 | 文字色・背景色・アクセント色。各色を初期の追従色に戻せる |
| 見出し | シンプル・アクセントライン・ネオン、初期アクセントライン |
| 背景画像 | ローカル画像またはHTTPS画像URL。濃さ0〜0.4、初期0.12 |

ライブ編集の選択行は元のMarkdown記法・インデントを表示し、それ以外のリスト項目の先頭行に字下げとガイドを適用します。8階層を超える表示は8階層目に揃えます。プレビューはHTMLのリスト階層を使います。

## プリセットと保存範囲

- **VS Codeに追従**：現在のVS Codeテーマに馴染む基本の外観。
- **ペーパー**：明朝・生成りの背景・茶色のアクセント。
- **ゲーミング**：濃紺の背景・ミント色のアクセント・ネオン見出し。点滅やアニメーションはありません。

プリセットは外観全体を切り替え、背景画像も初期化します。切り替え後に各項目を調整し、テーマ名を付けて保存できます。「初期値に戻す」も「適用」までは保存しません。

保存先は現在のVS Codeプロファイルの拡張設定領域（globalState）です。同じウィンドウで開いている専用画面にも反映します。他のウィンドウでは専用画面の再読み込み時に取得します。標準Markdownプレビューやサイドバーの外観設定には適用しません。

## 背景画像

「画像ファイルを選ぶ」はPNG・JPEG・WebP、2MB以内に対応します。元の画像を変更せず、拡張の保存領域へコピーし、`asWebviewUri` で表示します。画像のコピーは文書のUndo対象外で、キャンセルや画像を外す操作でもコピー済みのファイルは削除しません。

HTTPS画像はURLを入力して「URLを反映」を押します。配信元へのアクセスが発生し、オフラインや読み込み不可の場合は背景色のみになります。ローカル画像はJSONへBase64で埋め込み、HTTPS画像はURLを保存します。

## JSONの読み込み・保存

「JSONに保存」は現在試しているテーマをファイルへ保存します。「適用」とは独立しており、設定の永続化は行いません。「JSONを読み込む」は検証後に試着として表示し、「適用」で確定します。キャンセル・不正なJSON・対応外の形式・読み書き失敗では、保存済みの外観を維持します。

形式は `schemaVersion: 1` の全項目を持つJSONです。[ゲーミングのサンプル](../../../examples/themes/gaming.json)を基に編集できます。色は空文字（初期の追従色）または6桁の `#RRGGBB`。数値は上表の範囲で、未知の項目・任意CSS・スクリプト・SVG背景は受け付けません。JSONファイルの上限は約3MBです。保存先は `.json` に限定します。
