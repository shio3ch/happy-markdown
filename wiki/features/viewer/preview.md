# プレビュー

- ライト・ダークテーマ、本文検索、階層化した目次と見出しへの移動。
- 表、引用、折りたたみ、見出しリンク、言語名付きコードブロックの色分け。
- チェックリストの操作を元文書の `[ ]` / `[x]` に反映。全件完了後も完了数と総数を保持。
- 編集内容はまずVS Codeの文書に反映し、通常の保存・自動保存設定に従って保存。
