# プレビュー

- ライト・ダークテーマ、本文検索、階層化した目次と見出しへの移動。
- 目次はツールバーの目次アイコンから開く。本文検索の前後移動は矢印アイコン、Enterで次、Shift+Enterで前の一致へ移動できる。
- 表、引用、折りたたみ、見出しリンク、言語名付きコードブロックの色分け。
- `mermaid` コードブロックを図として表示。ライト・ダークの切り替えで再描画し、構文エラー時はエラーと元のコードを残します。専用画面が対象で、標準Markdownプレビューには描画スクリプトを追加しません。
- Mermaidは拡張に同梱し、CDNや外部の描画サービスを使いません。図内のリンク・スクリプト・HTMLラベル・外部画像は無効です。文書内の設定による描画設定の上書きは受け付けず、1図50,000文字・500辺を上限とします。数式・外部アイコンなど追加リソースを要する表示は保証しません。
- チェックリストの操作を元文書の `[ ]` / `[x]` に反映。全件完了後も完了数と総数を保持。
- 編集内容はまずVS Codeの文書に反映し、通常の保存・自動保存設定に従って保存。
- 見出し・文字装飾・リンク・引用・コード・チェックボックス・水平線の基本書式はライブ編集と共通。見出し下の装飾線は表示せず、文書に明示された水平線を表示する。共通CSSを使うVS Code標準Markdownプレビューにも見出しの装飾線削除を適用。
