# Happy Markdown

VS CodeでMarkdownをもっと心地よく書くための拡張機能です。

Obsidianのようなリッチな編集体験を目指し、文章の見た目を確かめながら、書くことに集中できるMarkdownエディターを育てていきます。

## 目指す体験

- 見出しや装飾、リスト、表、画像を直感的に扱える編集。
- 書くことと読むことが自然につながる、読みやすい表示。
- VS Codeのテーマや文書管理と馴染む、日常的に使える環境。
- Markdownファイルをそのまま活かし、安心して編集を続けられること。

## 開発状況

現在はCodeMirrorを使い、Markdownの見出し・文字装飾・リスト・引用・コード・表などを編集画面へ反映するライブ編集を実装しています。文章はカーソルや選択範囲のある行の記法を直接修正でき、テーブルは表のままセルへの入力、行・列の追加・削除・並べ替え、表全体の削除ができます。チェックリストもその場で操作できます。装飾の挿入、専用プレビューへの切り替え、本文検索、目次、VS Codeの文書との同期を備えています。

サイドバーではMarkdownのファイル一覧・ワークスペース内の本文検索・ブックマークを切り替えられます。本文検索はサイドバー内で入力と同時に結果を更新します。ファイル・フォルダーの新規作成、ファイルのドラッグ移動、右クリックからの複製・コピー・切り取り・貼り付け・名前変更・削除にも対応しています。ファイル操作のショートカットはVS Codeのキーバインド機構で登録し、ユーザー設定で変更できます。

Mermaidの図を専用画面のプレビューとライブ編集で表示できます。ライブ編集では図と元の記法を切り替えて確認できます。図をドラッグして編集する機能は未実装です。

実装はTypeScriptに移行し、拡張ホストとWebviewの型検査を導入しています。専用画面とサイドバーのファイル一覧・検索・ブックマークは、部品ごとのReactコンポーネントで構成し、テキスト編集にはCodeMirrorを使用しています。

リッチな編集体験に向けて開発中です。画像のインライン描画や、文書全体の完全なWYSIWYG編集はまだ実装していません。
