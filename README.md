# Happy Markdown

VS CodeでMarkdownをもっと心地よく書くための拡張機能です。

Obsidianのようなリッチな編集体験を目指し、文章の見た目を確かめながら、書くことに集中できるMarkdownエディターを育てていきます。

## 目指す体験

- 見出しや装飾、リスト、表、画像を直感的に扱える編集。
- 書くことと読むことが自然につながる、読みやすい表示。
- VS Codeのテーマや文書管理と馴染む、日常的に使える環境。
- Markdownファイルをそのまま活かし、安心して編集を続けられること。

## 開発状況

現在はCodeMirrorを使ったMarkdownテキスト編集と、専用プレビューの切り替えを実装しています。装飾の挿入、本文検索、目次、チェックリストの編集、VS Codeの文書との同期を備えています。

リッチな編集体験に向けて開発中で、WYSIWYG編集はまだ実装していません。
